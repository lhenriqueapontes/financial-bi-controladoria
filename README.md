# Financial BI Controladoria

Projeto demonstrativo de BI financeiro e controladoria com DRE sintética, fluxo de caixa e indicadores gerenciais.

## Objetivo

Demonstrar habilidades em análise financeira, modelagem de dados, visualização e apoio à decisão usando Python e dados seguros.

## Problema de negócio

Controllers e analistas financeiros precisam transformar dados de receitas, custos, despesas e caixa em indicadores claros para decisões de gestão. Este projeto mostra uma pipeline simples e reprodutível.

## Stack

- Python
- pandas e NumPy
- Matplotlib/Plotly
- Jupyter Notebook
- CSV sintético

## Estrutura

```text
src/
  generate_financial_data.py
  kpis.py
data/
  README.md
notebooks/
  dre_fluxo_caixa.ipynb
reports/
  dashboard_summary.md
assets/
```

## Indicadores

- Receita bruta e líquida
- Custo e margem bruta
- EBITDA demonstrativo
- Lucro líquido
- Fluxo de caixa mensal
- Variação orçado x realizado

## Cargos-alvo

Analista de BI, Analista Financeiro, Controller, Analista de Dados, Analista Contábil com dados.

## Segurança

Não há dados contábeis reais, clientes, empresas identificáveis, documentos fiscais ou informações sensíveis. Todo dado é sintético ou público.
